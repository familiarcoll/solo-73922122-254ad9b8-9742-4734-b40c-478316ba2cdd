# 水文数据接入采集(SSRF 防护演示)

采集机需要按合作方提供的链接拉取原始观测 CSV,同时采集机网络可达内网管理服务
(禁区)。本工程在采集端实现「接入边界」防护:用户提交的链接无论直接指向禁区、
经重定向跳入禁区、还是借 DNS 换址(重绑定)偷袭,都不能越过边界。

## 组成

| 服务 | 容器内地址 | 说明 |
|---|---|---|
| `web` | 172.28.0.5:8000 | FastAPI 采集网页(对外映射 `localhost:8000`) |
| `source` | 172.28.0.10:8080 | 本地观测源(CSV、各类跳转、超限文件) |
| `forbidden` | 172.28.0.200:8080 | 禁区服务(内网管理服务模拟,带请求计数) |
| `dns` | 172.28.0.53:53/UDP + 8081 | 演示 DNS,`rebind.hydro.local` 首查后自动换址 |

许可策略(管理员在 `docker-compose.yml` 的 `web.environment` 配置):
`ALLOWED_CIDRS=172.28.0.0/25`(覆盖 web/source/dns,**不含**禁区 .200)、
`ALLOWED_PORTS=8080`、`MAX_REDIRECTS=3`、`MAX_BYTES=262144`(256 KiB)。

## 防护模型(collector/guard.py)

1. 仅 `http://`、仅 IPv4;拒绝携带用户信息的 URL。
2. **逐跳裁决**:每一跳连接前解析主机名,核对**全部**解析地址——任何一个落在
   许可网段之外(混有禁区地址)整跳即拒;端口也须在许可列表内。
3. **连接已核对地址**:实际 TCP 连接直接打到已通过裁决的 IP,并**保留原 Host**
   头;连接阶段不再发生任何新的 DNS 解析,因此 DNS 事后换址无法把请求带进禁区。
4. **重定向逐跳重新裁决**:相对跳转用 `urljoin` 正常接续;超过 3 次跳转或任一
   步失败,本次采集整体失败,不开放下载。
5. 响应体超过 256 KiB 即拒绝,不落盘;成功原件保存到 `DOWNLOAD_DIR` 并可下载。

## 启动

```bash
docker compose up --build
# 打开 http://localhost:8000
```

网页场景按钮(仅填充链接,全部走同一条防护路径):

| 场景 | 预期 |
|---|---|
| 正常采集 | 下载 `obs.csv` 成功 |
| 相对跳转 | 302 → `/obs.csv`,正常接续成功 |
| 跳转入禁区 | 第二跳解析到 172.28.0.200,拒绝;禁区计数不变 |
| DNS 换址 | 首跳正常,第二跳 `rebind.hydro.local` 换成禁区地址,拒绝;禁区计数不变 |
| 超限文件 | 超过 256 KiB,拒绝 |
| 跳转循环 | 超过 3 次跳转,拒绝 |

页面同时展示:采集策略、每跳的解析地址/实际连接/裁决记录、下载列表、
禁区请求计数(每 3 秒自动刷新)。

## 本地自测(无需 Docker)

```bash
pip install fastapi uvicorn   # 运行网页与服务所需
python3 tests/selftest.py
```

在 127.0.0.x 上启动全部四个组件,跑 37 项断言:DNS 换址行为、逐跳裁决、
保留原 Host、相对/绝对跳转、超限、跳转上限、端口/方案/用户信息拒绝、
混合地址拒绝、禁区计数不变、网页端到端等。

## 管理配置项(web 服务环境变量)

| 变量 | 默认 | 说明 |
|---|---|---|
| `ALLOWED_CIDRS` | `172.28.0.0/25` | 许可网段,逗号分隔 |
| `ALLOWED_PORTS` | `8080` | 许可端口,逗号分隔 |
| `MAX_REDIRECTS` | `3` | 最大跳转次数 |
| `MAX_BYTES` | `262144` | 原件大小上限 |
| `FORBIDDEN_STATS_URL` | `http://forbidden.hydro.local:8080/stats` | 禁区计数读取地址 |
| `DNS_RESET_URL` | `http://dns.hydro.local:8081/reset` | 演示 DNS 复位地址 |
| `SCENARIO_SOURCE_BASE` / `SCENARIO_REBIND_URL` | 见 compose | 页面场景按钮链接 |
| `DOWNLOAD_DIR` | `./data/downloads` | 原件保存目录 |

## 已知限制(如实说明)

- 仅支持 `http://`(不处理 TLS);仅 IPv4,符合需求约定。
- 禁区计数、DNS 复位是**管理通道**直连(管理员配置的固定地址,不接收用户输入),
  不经过 GuardedFetcher;真实部署应对该监控通道单独鉴权/隔离。
- 采集记录与文件元数据存于内存,重启即清空(原件文件保留在 DOWNLOAD_DIR)。
- 演示 DNS 只实现 A 记录应答,非通用 DNS。
- 单地址连接失败会依次尝试其余**已核对**地址;全部失败则本跳失败。
